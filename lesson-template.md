# Шаблон урока News Impact Agents

## Роль в сквозном проекте
Какой слой Chip News Impact Engine строится в этом уроке.

## Цель урока
Один проверяемый результат обучения.

## Входное состояние проекта
Файлы, которые ученик открывает до начала работы.

## Подготовка окружения
`conda activate py11`, проверка CLI, тестов и `config.env` без раскрытия секретов.

## Agentic задание через agy
Один воспроизводимый prompt для `agy --print --sandbox --add-dir "$(pwd)"` или `agy --prompt-interactive --add-dir "$(pwd)"`, запущенный из корня репозитория.

## Разбор руками
Входы, выходы, риски, false positives, human-review points.

## Практика
Команды, изменение данных, запуск тестов/evals.

## Ожидаемый результат
Что должно стать понятным или работающим.

## Мини-тест
4 вопроса на понимание архитектурного решения.

## Ответы для самопроверки
Краткие эталонные ответы, чтобы ученик мог сравнить свои выводы с требуемым уровнем.

## Критерий перехода дальше
Условие, без которого следующий урок начинать нельзя.
