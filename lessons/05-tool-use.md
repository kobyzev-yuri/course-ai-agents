# Урок 5. Tool use: как агент безопасно действует во внешнем мире

## Цель
Понять, как агент выбирает инструменты, вызывает их и обрабатывает результаты без потери контроля.

## Ключевые понятия
tool schema, permissions, structured inputs, side effects, sandbox, tool result validation.

## Подготовка окружения

Перед уроком активируйте окружение и установите зависимости для tool calling:

```bash
conda activate py11
pip install openai python-dotenv
```

Проверьте `config.env`: нужны `OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1` и `OPENAI_API_KEY`. В этом уроке используется безопасный mock tool, поэтому внешние API и реальные побочные эффекты не требуются.

## Теория: 10-15 минут

- Инструменты превращают модель из генератора текста в исполнителя: поиск, API, файловая система, терминал, браузер, базы данных.
- Каждый инструмент должен иметь контракт: входные параметры, ожидаемый результат, ошибки, права и побочные эффекты.
- Безопасный агент использует минимально нужные права и валидирует результаты инструментов перед следующим шагом.

## Яркий пример
Агент-аналитик вызывает API продаж, проверяет схему ответа, считает аномалии и возвращает список клиентов, где нужна ручная проверка.

## Практика: 15-25 минут

- Для задачи “собрать отчет о конкурентах” выберите инструменты и права.
- Опишите, какие tool calls должны требовать подтверждения.

## Практический запуск

Запустите пример с безопасным mock tool call:

```bash
conda activate py11
python course-ai-agents/examples/05_tool_use_agent.py
```

Разберите, почему `get_order_status` безопасен для учебного примера: он детерминированный, не пишет во внешние системы и явно возвращает risk level.

## Мини-тест
1. Почему важна схема инструмента?
   - A. Чтобы агент вызывал его предсказуемо
   - B. Чтобы скрыть ошибки
   - C. Чтобы заменить тесты
2. Какой инструмент обычно требует повышенного контроля?
   - A. Отправка email или платежа
   - B. Форматирование текста
   - C. Подсчет слов
3. Что значит least privilege?
   - A. Дать только необходимые права
   - B. Дать все права сразу
   - C. Отключить логи

## Ответы
1. A — Чтобы агент вызывал его предсказуемо
2. A — Отправка email или платежа
3. A — Дать только необходимые права
