# Урок 9. CrewAI: ролевые команды агентов

## Цель
Понять, как строить multi-agent прототипы через роли, цели и задачи в CrewAI.

## Ключевые понятия
agent role, goal, backstory, task, crew, sequential process, hierarchical process.

## Подготовка окружения

Перед уроком активируйте окружение и установите CrewAI:

```bash
conda activate py11
pip install openai python-dotenv crewai
```

Проверьте `config.env`: `OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1`, `OPENAI_API_KEY`, опционально `OPENAI_MODEL`. CrewAI-пример использует OpenAI-compatible настройки через переменные окружения.

## Теория: 10-15 минут

- CrewAI хорошо ложится на человеческую метафору команды: researcher, analyst, writer, reviewer, manager.
- Каждый агент получает роль, цель, контекст и набор задач; результаты передаются по workflow.
- Sequential process подходит для линейного pipeline, hierarchical process — для делегирования через manager-agent.

## Яркий пример
Команда “researcher + analyst + editor” готовит market brief: поиск источников, выделение инсайтов, редактура и финальный отчет.

## Практика: 15-25 минут

- Разбейте подготовку лендинга на 4 роли CrewAI.
- Опишите задачи и expected output для каждого агента.

## Практический запуск

Запустите CrewAI-пример market brief:

```bash
conda activate py11
python course-ai-agents/examples/09_crewai_market_brief.py
```

После запуска определите, какие артефакты передаются между researcher, analyst и editor.

## Мини-тест
1. Что является центральной метафорой CrewAI Crews?
   - A. Команда ролей с задачами
   - B. Только граф состояний
   - C. Один prompt без инструментов
2. Когда удобен hierarchical process?
   - A. Когда нужен менеджер для делегирования
   - B. Когда все шаги строго один за другим
   - C. Когда нет задач
3. Что надо задавать агенту в CrewAI?
   - A. Роль, цель и задачи
   - B. Только цвет интерфейса
   - C. Только температуру

## Ответы
1. A — Команда ролей с задачами
2. A — Когда нужен менеджер для делегирования
3. A — Роль, цель и задачи
