# Урок 3. Antigravity как практическая среда агентной работы

## Цель
Понять Antigravity как рабочую поверхность для постановки задач, наблюдения за агентами и проверки результатов.

## Ключевые понятия
manager surface, artifacts, parallel agents, editor-terminal-browser loop, workspace isolation.

## Подготовка окружения

Перед уроком подготовьте agentic workspace:

```bash
conda activate py11
pip install openai python-dotenv
```

Проверьте `config.env` с `OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1` и `OPENAI_API_KEY`. Для Antigravity также подготовьте отдельную рабочую папку, где агент сможет создавать артефакты проверки: логи, скриншоты, walkthrough или краткий отчет.

## Теория: 10-15 минут

- Antigravity полезна как среда, где агент может работать не только с текстом, но и с кодом, терминалом, браузером и артефактами проверки.
- Менеджерская поверхность меняет роль пользователя: вместо микроконтроля каждого шага он формулирует задачу и проверяет результат.
- Параллельные агенты позволяют разделять работу: один пишет код, второй готовит тесты, третий проверяет UX или документацию.

## Яркий пример
Запрос: “Добавь пустое состояние в список заказов”. Агент меняет компонент, запускает приложение, открывает экран в браузере, делает скриншот и объясняет, что изменил.

## Практика: 15-25 минут

- Сформулируйте задачу для Antigravity-агента с явными acceptance criteria.
- Разделите одну большую задачу на 3 параллельные агентные подзадачи.

## Мини-тест
1. Какая роль у artifacts?
   - A. Дать проверяемое доказательство выполненной работы
   - B. Увеличить число токенов
   - C. Заменить требования
2. Когда полезны параллельные агенты?
   - A. Когда задачи независимы или проверяют друг друга
   - B. Когда надо скрыть ошибки
   - C. Только для простого чата
3. Что делает пользователь в agent-first среде?
   - A. Ставит задачу и проверяет артефакты
   - B. Пишет каждый символ за агента
   - C. Отключает инструменты

## Ответы
1. A — Дать проверяемое доказательство выполненной работы
2. A — Когда задачи независимы или проверяют друг друга
3. A — Ставит задачу и проверяет артефакты
