# Урок 13. Безопасность и контроль: права, секреты, sandbox, audit trail

## Цель
Научиться проектировать агентные системы с учетом данных, прав, секретов и prompt injection.

## Ключевые понятия
least privilege, sandbox, secrets management, prompt injection, audit trail, data boundary.

## Подготовка окружения

Перед уроком активируйте окружение и проверьте конфигурацию без раскрытия секретов:

```bash
conda activate py11
pip install openai python-dotenv
```

Убедитесь, что `config.env` существует, но не вставляйте `OPENAI_API_KEY` в prompts, отчеты, скриншоты или учебные ответы. В этом уроке ключ рассматривается как секрет, а не как часть учебного материала.

## Теория: 10-15 минут

- Агент с инструментами — это исполнитель с правами, поэтому безопасность начинается с ограничения доступа.
- Prompt injection особенно опасен, когда агент читает внешние данные и затем выполняет команды или отправляет информацию.
- Audit trail нужен для разборов: кто поставил задачу, какие tool calls были сделаны, какие данные использованы, кто подтвердил действие.

## Яркий пример
CRM-agent читает тикеты клиентов. Он может суммаризировать запросы, но не должен раскрывать персональные данные в сторонние API или отправлять письма без approval.

## Практика: 15-25 минут

- Найдите 5 угроз для агента с доступом к email.
- Опишите permission model для research-agent.

## Мини-тест
1. Что такое prompt injection?
   - A. Попытка внешнего текста изменить поведение агента
   - B. Обычный системный prompt
   - C. Сжатие контекста
2. Почему sandbox полезен?
   - A. Ограничивает среду и последствия ошибок
   - B. Ускоряет модель
   - C. Убирает необходимость логов
3. Что должно быть в audit trail?
   - A. Tool calls, решения, подтверждения и артефакты
   - B. Только финальная фраза
   - C. Ничего

## Ответы
1. A — Попытка внешнего текста изменить поведение агента
2. A — Ограничивает среду и последствия ошибок
3. A — Tool calls, решения, подтверждения и артефакты
