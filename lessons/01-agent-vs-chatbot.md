# Урок 1. Что такое AI-агент и чем он отличается от чатбота

## Цель
Понять, почему агент — это не просто диалоговая модель, а система, которая принимает цель, планирует действия, использует инструменты и проверяет результат.

## Ключевые понятия
goal-driven behavior, autonomy level, tool use, state, feedback loop, artifact.

## Подготовка окружения

Перед уроком активируйте окружение и убедитесь, что базовые LLM-пакеты доступны:

```bash
conda activate py11
pip install openai python-dotenv
```

Проверьте `config.env` в корне workspace:

```bash
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
```

Если `OPENAI_MODEL` не задан, учебные примеры используют `gpt-4o-mini`.

## Теория: 10-15 минут

- Чатбот обычно отвечает на сообщение здесь и сейчас. Агент получает цель и выполняет последовательность действий, пока не достигнет проверяемого результата.
- Архитектура агента включает модель, инструкции, инструменты, рабочую среду, память/состояние и механизм проверки.
- Степень автономности может быть разной: от ассистента, который предлагает следующий шаг, до агента, который сам запускает тесты, исправляет ошибки и приносит артефакт проверки.

## Яркий пример
Агент получает задачу “исправить баг в форме оплаты”. Он читает код, воспроизводит ошибку, вносит изменение, запускает тесты, проверяет UI в браузере и возвращает краткий отчет со скриншотом.

## Практика: 15-25 минут

- Разберите 5 сценариев и отметьте, где достаточно чатбота, а где нужен агент.
- Для одного агентного сценария запишите цель, инструменты и критерий завершения.

## Практический запуск

Запустите минимальный пример агента:

```bash
conda activate py11
python course-ai-agents/examples/01_minimal_agent.py
```

После запуска отметьте в ответе агента три части: план, следующее действие и критерий проверки.

## Мини-тест
1. Что лучше всего отличает агента от чатбота?
   - A. Красивый интерфейс
   - B. Цель, действия через инструменты и проверка результата
   - C. Более длинный ответ
2. Какой компонент позволяет агенту действовать за пределами текста?
   - A. Температура модели
   - B. Инструменты
   - C. Название агента
3. Что является хорошим критерием завершения?
   - A. Агент написал “готово”
   - B. Пройдены тесты и создан отчет
   - C. Ответ получился длинным

## Ответы
1. B — Цель, действия через инструменты и проверка результата
2. B — Инструменты
3. B — Пройдены тесты и создан отчет

## Домашнее задание
Описать агентный workflow для одной личной или рабочей задачи: вход, действия, инструменты, проверка результата.

## Критерий готовности
Слушатель может объяснить архитектурное решение урока, применить его к новому сценарию и назвать минимум один риск неправильного применения.
