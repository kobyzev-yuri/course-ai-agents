# Проверка понимания

Вместо набора случайных вопросов курс использует повторяющийся контроль после каждого урока:

1. Какой вход получает слой системы?
2. Какой структурированный выход он обязан вернуть?
3. Где возможна ошибка evidence, mapping или scoring?
4. Где нужен human review, skeptic review или eval?

## Ответ-ориентир
Хороший ответ всегда ссылается на конкретные файлы проекта, пример новости из `data/sample_news.jsonl`, label из `ImpactAssessment` и команду проверки. Ответы вида “агент сам решит” не принимаются.

## Финальный eval
Главная проверка курса:

```bash
python evals/run_eval.py
```

Минимальный проходной score для учебного прототипа: `0.8`.
